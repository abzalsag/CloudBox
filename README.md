# CloudBox

**CloudBox** — backend-сервис для хранения и управления файлами, разработанный на Go (Golang). Проект предназначен для изучения и практического применения современных технологий backend-разработки.


Статус проекта: В активной разработке (Work in Progress).


## Технологический стек

| Технология | Назначение |
|---|---|
| Go (Golang) | Разработка backend |
| PostgreSQL | Хранение данных пользователей и метаданных файлов |
| sqlc | Генерация типобезопасного Go-кода на основе SQL-запросов |
| pgx | Работа с PostgreSQL |
| MinIO | Объектное хранилище файлов с поддержкой S3 API |
| JWT | Аутентификация и авторизация |
| Docker | Контейнеризация приложения и инфраструктуры |
| golang-migrate | Управление миграциями базы данных |
| godotenv | Загрузка переменных окружения |

## Основные возможности

- Регистрация пользователей
- Аутентификация с использованием JWT
- REST API
- Загрузка и скачивание файлов
- Хранение метаданных файлов в PostgreSQL
- Хранение файлов в MinIO
- Контроль доступа к пользовательским файлам

*Некоторые возможности находятся в разработке.*

## Архитектура

CloudBox использует разделение метаданных и содержимого файлов:

- **Go API** — обработка HTTP-запросов и бизнес-логика.
- **PostgreSQL** — хранение информации о пользователях и метаданных файлов.
- **MinIO** — объектное хранилище для содержимого файлов.
- **JWT** — защита приватных API-эндпоинтов.

## Запуск проекта

### Требования

- Go
- Docker и Docker Compose
- PostgreSQL
- MinIO

### 1. Клонирование репозитория

```bash
git clone https://github.com/abzalsag/CloudBox.git
cd CloudBox
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта и укажите необходимые настройки приложения.

Пример конфигурации:

```env
APP_PORT=8080
DATABASE_URL=postgres://cloudbox:cloudbox@localhost:5434/cloudbox?sslmode=disable

JWT_SECRET=your_secret_key

MINIO_ENDPOINT=localhost:9000
MINIO_ACCESS_KEY=your_access_key
MINIO_SECRET_KEY=your_secret_key
MINIO_BUCKET=cloudbox
MINIO_USE_SSL=false
```

Названия переменных должны соответствовать конфигурации приложения. Не публикуйте реальные секреты в репозитории.

### 3. Запуск инфраструктуры

```bash
docker compose up -d
```

### 4. Применение миграций

```bash
migrate -path migrations \
  -database "postgres://cloudbox:cloudbox@localhost:5434/cloudbox?sslmode=disable" up
```

### 5. Генерация SQL-кода

```bash
sqlc generate
```

### 6. Запуск приложения

```bash
go run ./cmd/api
```
